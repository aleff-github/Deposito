This Server Is a Tor Relay Node

🧅 What Does That Mean?

This server participates in the Tor network as an intermediate relay. Its job is to route encrypted traffic within Tor to support privacy and decentralization.

🔐 No Traffic Exits Here

This is not an exit node. No user traffic leaves this machine to the public Internet. All data remains encrypted and is forwarded only to other Tor relays.

If you are a network administrator or abuse desk:
This is a non-exit relay and does not generate outgoing Internet traffic from Tor users. Please consult Tor Project documentation before taking any action.
